# Tasks

## Apply VSCode Dark Theme colors to the entire application

Use the standard VSCode Dark+ theme colors throughout the app:
- Background: #1E1E1E
- Secondary background (panels, dialogs): #252526
- Input fields background: #3C3C3C
- Border / separator: #474747
- Primary text: #D4D4D4
- Secondary text / labels: #9D9D9D
- Selection / highlight: #094771
- Accent / active element: #007ACC
- Button background: #0E639C
- Button text: #FFFFFF
- DataGridView header background: #252526
- DataGridView row background: #1E1E1E
- DataGridView alternating row: #252526
- DataGridView grid lines: #474747

Apply these colors to: main form, all dialogs, DataGridView, buttons, input fields, labels, toolbars, and comboboxes.
